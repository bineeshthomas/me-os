# Contributing

Thanks for helping. A few ground rules keep Me-OS what it is:

1. **Privacy first.** No analytics, no telemetry, no accounts, no calls to new outside services. Anything that contacts
   the internet must be optional, **off by default**, explained in *Settings → Privacy*, and listed in the README.
2. **Local only.** Don't add features that need the app to be reachable from the network.
3. **Keep it simple.** One person, one computer, a calm interface.

## Setup

See *Development* in the [README](README.md). Run `npm run build` before opening a pull request: it type-checks the client
and the server.

## Pull requests

- Keep them small and focused, and describe what you changed and why.
- Check your change at phone width (about 390px) and on a laptop (about 1300px) before submitting.
- By contributing you agree your work is released under the [MIT licence](LICENSE).
